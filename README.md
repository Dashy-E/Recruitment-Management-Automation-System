# Recruitment App

This project now uses the Vite React app in `frontend/` as the active application.

## Structure

```text
recruitment app/
  frontend/   Vite + React app
  backend/    Placeholder for a future API service
```

## Run The Frontend

```bash
cd frontend
npm install
npm run dev
```

Vite will print a local URL, usually `http://localhost:5173/`.

## Build And Check

```bash
cd frontend
npm run build
npm run lint
```

Do not run root-level npm commands. The root Next.js scaffold was removed.
